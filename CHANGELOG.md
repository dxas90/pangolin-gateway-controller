## [0.1.0] - 2026-03-12

### Added

- Gateway API controller with 5-tier reconciliation model (Gateway, Newt, HTTPRoute, GRPCRoute, GatewayClass)
- Pangolin Integration API client with bearer token authentication
- Circuit breaker for Pangolin API calls (custom implementation, no external dependency)
- Typed error handling via `PangolinAPIError` with `IsRetryable()`, `IsNotFound()`, `IsConflict()` helpers
- Prometheus metrics: 10+ metrics covering reconciliation, API latency, resource counts
- Exponential backoff rate limiter (token bucket + exponential backoff) for all controllers
- Status conditions with `observedGeneration` tracking on all managed resources
- Conflict retry pattern using `retry.RetryOnConflict()` for status updates
- Field indexing for O(1) lookups (Gateway by GatewayClassName, routes by parent Gateway)
- Controller owner references for automatic garbage collection of child resources
- Concurrent reconciliation (3-5 workers per controller)
- Kubernetes Events via `recorder.Eventf()` throughout all controllers
- Configuration validation at startup via `Validate()` method
- Build-time version injection via `-ldflags` in Makefile
- Enhanced readiness check (`/readyz`) that verifies live Pangolin API connectivity
- Leader election support for high availability
- RBAC with least privilege (generated by kubebuilder)
- Graceful shutdown with `terminationGracePeriodSeconds`
- Idempotent reconciliation with existence checks before resource creation
- Finalizers with operational runbook (`RUNBOOK.md`)
- Target metadata tracking with ownership labels for multi-route resource sharing
- Multi-backend weight support for canary deployments and weighted traffic splitting
- HTTPRoute controller split into 4 focused files (controller, helpers, targets, status)
- Helm chart with PodDisruptionBudget, NetworkPolicy, and ServiceMonitor templates
- Newt VPN auto-deployment (WireGuard) for Gateway resources
- SSO configuration via `gateway.pangolin.net/disable-sso` annotation
- GRPCRoute support for TCP/UDP services via `gateway.pangolin.net/protocol` annotation
- Pagination support for Pangolin API 1.16.0+ (`pageSize`/`page` query params)
- Config file support as alternative to environment variables
- Example manifests for path-based routing, canary, TCP/UDP, and full integration tests
